# Event Gumbo

A polished, mobile-first concept landing page for Event Gumbo.

## Run locally

Open `index.html` directly, or run a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

The project is ready for Netlify with `netlify.toml` included. The early-access form is configured for Netlify Forms with a spam honeypot.

## Files

- `index.html` page structure and copy
- `styles.css` visual system, layout, and animation
- `script.js` interactions and form behavior
- `netlify.toml` deployment and security headers
